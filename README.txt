САЙТ-ВИЗИТКА АНДРЕЯ ФИРСОВА — АВТОРСКИЕ БАРНЫЕ ЭКСКУРСИИ

Как открыть:
1. Распакуйте ZIP в отдельную папку.
2. Дважды нажмите index.html.
3. Для публикации на GitHub Pages загрузите все файлы в корень репозитория и включите Settings → Pages → Deploy from a branch → main /root.

Файлы:
- index.html — страница, текст и контакты.
- style.css — стили и мобильная адаптация.
- andrey.jpg — фотография Андрея.
- favicon.svg — иконка вкладки.
